# Real World Validation Plan

## 1. 当前是否已经达到真实内测标准

基本达到 7 天真实内测标准，前提是先导入一批真实 Hyperliquid seed wallets，并保持只读同步、信号生成、Telegram 和模拟盘运行。

## 2. 当前是否已经达到公网部署标准

未完全达到公网生产标准。可以做小范围受控部署，但需要先更换 `SECRET_KEY`，配置 HTTPS/反向代理，限制访问账号，备份 SQLite，并确认 Telegram 只发到测试群。

## 3. 当前最大的风险是什么

最大风险是 Discovery seed 钱包质量不足，导致信号样本偏少或噪音过高。第二风险是 ROI/PnL 为 Estimated，不能当作实盘收益依据。

## 4. 还缺什么才能进入小额实盘测试

- 至少跑满 7 天真实信号
- 至少 20-50 个高质量观察钱包
- 能证明 S/A 钱包 open/add 信号在模拟盘稳定优于随机
- 明确最大回撤和连续亏损阈值
- 人工审批流程稳定
- 仍需单独设计真实交易模块、私钥隔离、限额、熔断和审计

当前建议：先真实内测，不进入小额实盘。
